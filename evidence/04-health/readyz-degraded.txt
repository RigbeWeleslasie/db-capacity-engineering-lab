--- Honest scope note ---
This proves the actual mechanism nginx's upstream health check depends on:
/readyz genuinely flips 200 -> 503 -> 200 as the real Secrets Manager secret
is broken and fixed, using the SAME loadDbConfig()/getPool() code path the
deployed instance would use (DB_SECRET_ARN set, AWS_ENDPOINT_URL pointed at
LocalStack, real GetSecretValue call -- see boot lines above showing the
VersionId actually changing).

What's NOT demonstrated here: nginx itself pulling this instance out of
rotation. That requires the EC2 instance from modules/service to actually
be running, which is blocked by the LocalStack Docker-backed-AMI-discovery
gap documented in FIDELITY.md -- not something this test or the app code can
work around. modules/service's own nginx config (templates/nginx.conf.tftpl)
is written to proxy only to a /readyz-passing upstream; this evidence
confirms the signal it depends on is real, even though the EC2 layer that
would consume it can't currently be stood up in this environment.
