--- 3. Dump (local -> file) --------------------------------------------------
$ docker exec mysql-db mysqldump -uroot -plabpassword --databases capacity_lab \
    --single-transaction --routines --triggers --set-gtid-purged=OFF \
    > capacity_lab.sql

Result: 28,545,335 bytes (~28.5MB), 29 INSERT statements (mysqldump's default
extended-insert packs many rows per statement). Consistent with the ~31MB
on-disk table size noted in api/server.js's OPS-2204 comments.

--- 4. Restore (file -> Aiven, over TLS) -------------------------------------
$ mysql --host=$TF_VAR_aiven_host --port=$TF_VAR_aiven_port --user=avnadmin \
        --password=*** --ssl-ca=~/.aiven/ca.pem < capacity_lab.sql

(completed with no errors)
